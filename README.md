# Lemon Courses

Сайт практических курсов и технических статей по Next.js, Django и AI.

## Разработка

```bash
npm install
cp .env.example .env.local
npm run dev
```

Проверка перед публикацией:

```bash
npm run lint
npm run typecheck
npm run build
```

## Настройки

`SITE_URL` — постоянный адрес публичного сайта. Для deployment в Vercel устанавливается в настройках проекта.

`TRACKER_KEY` — серверный секрет для регистрации переходов; хранится только в переменных окружения и не публикуется в репозитории.

`TRACKER_URL` — серверный адрес пикселя трекера (необязательный, по умолчанию `/t.gif` на подключённом сервере).

Превью-сборки закрыты от индексации. На production доступны `robots.txt` и `sitemap.xml`.

## Страницы

- `/` — курсы и статьи
- `/articles` — каталог
- `/articles/[slug]` — технические статьи
- `/privacy` — политика конфиденциальности

Материалы предоставляются для ознакомления. Обучение и оплата курсов осуществляются через Stepik.
