# Lemon Courses — v0.4.1, 07.11.2026

Самостоятельный RU-сайт курсов Stepik. Next.js App Router, TypeScript, без кабинетов, LMS и собственного платёжного контура. Файлы `_sources/` и `docs/` перенесены из `lemon-courses-v1`; временная папка в пакете отсутствует.

## Запуск

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

Node >=20.9.0. Для Vercel — корень проекта `SD/lemon-courses`, конфигурация `.env.example`. При публикации новой версии из отдельного репозитория корень — этот каталог.

## Разделы

- `/` — 2 линейки по 3 курса с переходами на демо, статьи.
- `/articles` и `/articles/seo-nextjs-app-router`, `/articles/django-drf-nextjs-api` — первые два объясняющих материала P1/P2; инженерное соответствие текущему живому коду ещё нужно отдельно верифицировать.
- `/privacy`, `robots.txt`, `sitemap.xml`, канонические метаданные, 404.

## Аналитика v0.4

Клики отправляются в `POST /api/track` как `{event,src}`. Сервер проверяет **допустимую пару** и без раскрытия `TRACKER_KEY` делает GET на PythonAnywhere `/t.gif` с прежними параметрами `e`, `src`, `k`, `t`. При недоступности трекера переходы не блокируются. Без ключа события не посылаются. Тестовые события на рабочий трекер не отправлялись.

| Место | event | src |
| --- | --- | --- |
| Главная → Stepik | `главная_степик` | `курс_01` … `курс_06` |
| Главная → демо | `главная_проект` | `проект_01` … `проект_06` |
| Статья → Stepik | `статья_степик` | `статья_сео_nextjs__курс_06` или `статья_drf_nextjs__курс_02` |
| Статья → демо | `статья_проект` | `статья_сео_nextjs__проект_06` или `статья_drf_nextjs__проект_02` |

`проект_03` обозначает учебный результат курса 3, даже если демо URL временно совпадает с курсом 2. Это идентификатор проекта **в каталоге курсов**, а не гарантия уникального URL.

Stepik UTM: `utm_source=lemon_courses`, `utm_medium=site`, `utm_campaign=поиск_курсы_2026`, `utm_content=курс_XX` для главной или `статья_...__курс_XX` для статьи.

## Публикация / индексация

1. Публикуйте **как Vercel production**, с Root Directory `lemon-courses` при работе из репозитория `SD`, либо корнем проекта при отдельном репозитории.
2. Укажите `TRACKER_KEY` **только** в Environment Variables Vercel, Production. `TRACKER_URL` опционален, по умолчанию `https://lemon1964.pythonanywhere.com/t.gif`.
3. Укажите `SITE_URL` равным **фактически присвоенному production-адресу**, без завершающего `/`. Пример `https://lemon-courses.vercel.app` — только кандидат; наличие адреса нужно проверить в Vercel. Не публикуйте с чужим или неподтверждённым canonical.
4. `VERCEL_ENV=production` автоматически включает index/follow, `robots.txt` c Allow и полный `sitemap.xml`. В Vercel Preview (`VERCEL_ENV=preview`) и локальном dev сайт получает noindex/nofollow, robots Disallow, пустой sitemap. Не задавайте `VERCEL_ENV` вручную.
5. Файлы проверки собственности Google/Яндекс помещайте в `public/` по инструкции поисковиков, без добавления verification env.
6. После деплоя проверьте все пути, мета-теги, `robots.txt`, `sitemap.xml` и отдельные события в статистике. Внешние реальные ссылки требуют live-проверки.

`docs/` и `_sources/` исключены из Git по решению LEMON, но сохранены в полном handoff-архиве. Никаких новых статей и правок P1/P2 в этом релизе.

## Границы версии

- P3/P4 не опубликованы: требуются проверка учебного кода и правил провайдеров.
- Демо и курсовые URL взяты из `Stepik/Course-1..6/0-promo.md`; живые демо и фактические редиректы не проверены автоматически.
- Для визуального старта использован самостоятельный CSS в духе референса с зелёным акцентом и синим вторичным; изображения/скриншоты не нужны, позже можно добавить реальные снимки проектов.
- Контакты открывают почтовую программу кликом, адрес не присутствует в HTML как `mailto:`.
- `/privacy` — проектная политика по имеющемуся поведению, нужна оценка владельца перед публикацией.

## Проверки

- LEMON подтвердил успешные `npm run lint`, `npm run typecheck`, `npm run build`, основные страницы и рабочий трекер **для предыдущей v0.3**.

- Статическая проверка маршрутов, схемы источников и файла архива выполнена, без реальных событий трекера. Сведения в `docs/FORGE/04_V0-4-PUBLIC-LAUNCH-HANDOFF-2026-11-07.md`.

## Перезапись из SD/incoming

Поместить распакованный обновлённый `lemon-courses/` в `SD/incoming/lemon-courses/`. Из `SD`:

```bash
bash incoming/lemon-courses/template-overwrite.sh
cd lemon-courses
npm install
npm run lint
npm run typecheck
npm run build
```

Защищены `.git/`, `.env.local`, `node_modules/`, а локальные документы `docs/` и исходники `_sources/` дополняются/обновляются без удаления отсутствующих во входящем ZIP файлов. Каталог `.next/` сбрасывается. Не используйте `--delete-excluded`. Проверьте `git status` перед коммитом.

Исправлена ошибка TypeScript в `src/app/api/track/route.ts`: перед передачей `src` в `URLSearchParams` теперь явно проверяется тип `string`.
